## Remaining Findings

1. **P2: Desktop workflow verification remains incomplete.** The latest unit/integration-test collector covers 49.9% of instrumented production C# lines (5,719/11,468), excluding tests. Truth is 84.2%; Continuum 65.2%; Host 42.9%; App 37.4%; Abyss 80.3%; Contracts 100%. Desktop executable/tools are not loaded by that collector, although published and installed executable smoke tests run separately. These percentages are not defect probabilities or a commercial certification. Manual sign-in/sign-out, all six modules, synthetic user/assistant capture without restart duplication, basic Abyss recall/source lines and Clear, bounded Pulse fallback staging, Chronicle rebuild/cancellation, Portal's basic synthetic-image paste with selected-draft preservation, owner-disabled capture persistence, two declined native busy-exit warnings, confirmed busy-exit shutdown/restart, isolated wipe/restart and host-bridge disarming on Google sign-in have passed on their identified builds. The current standalone Return pill passed owner provider-layout and return/Control Centre checks. Model-enriched Pulse before its deadline, remaining live draft/focus/clipboard failure and navigation safeguards, live same-origin authentication-route traversal, recovery-window keyboard/close routing, multi-monitor/DPI, accessibility, and long-session tests remain. Full-module Abyss and asynchronous Chronicle JavaScript fixtures improve coverage but are not a realistic full ChatGPT DOM suite.

2. **P2: Distribution validation is not yet complete.** The v5.1.0 executable and both installer variants compile and pass local validation, but are unsigned. Exact v5.0.0 Truth-source compatibility and a repackaged isolated v5.0.0-to-v5.1.0-to-v5.0.0 payload matrix passed, including backups, deduplication, version registration, complete payload file inventory and synthetic data retention. This does not exercise original customer installers or legacy desktop runtime rollback. The original published installer has been checksum-verified and staged in a guarded disposable-machine kit, not executed here. Remote CI has not run for this local branch. Complete the supported-machine matrix, approve licensing and privacy policies, sign the artifacts, and obtain explicit publishing approval.

3. **P3: Large-archive performance and cache retention need bounded policies.** Recall scans and caches complete archives; Truth indexes and session metadata remain in memory for the process lifetime. Pulse projection performs significant synchronous file/text processing. Benchmark representative long histories, cap/evict caches, avoid UI-thread projections, and consider an incremental local search index only after measuring the current baseline. Cancellation now reaches Pulse's synchronous projection before its UI cleanup callback, but this is not a performance benchmark.

4. **P3: Archive deduplication is not a lossless message transcript.** The synthetic Chronicle test rendered six turns but stored four distinct-content lines: identical repeated Signal prompts/replies collapse under the existing archive fingerprint format. This preserves current compatibility and content recall, not the multiplicity of repeated messages. If exact per-turn history is a product requirement, introduce durable message identity with an explicit compatibility/migration design rather than silently changing existing archive semantics during release validation.

Thirteen new transfer cases cover these failure boundaries without reading the real clipboard or injecting native keys. - Delayed capture/completion events no longer move the active session. Blocked commands cannot update session state. Flush acknowledgements require the requested conversation, and operation IDs are no longer reused after forced cancellation.

- Portal now preserves unsent staging, checks trusted browser readiness and VAL foreground focus before paste, has a valid tested composer-focus script, hashes all image pixels in bounded blocks, and releases native hooks/listeners.
