# VAL v5.1.0

VAL v5.1.0 updates the desktop foundation to .NET 10 LTS, strengthens local-data and workflow safety, and introduces the approved gunmetal/glass control treatment with adaptive Control Centre placement and keyboard access.

## Highlights

- Migrated the application, feature assemblies and development toolchain to .NET 10; the Windows x64 installer includes the application runtime.
- Hardened local data wipe, deferred cleanup, atomic storage and cancellation so incomplete operations fail safely and preserve committed archives where appropriate.
- Improved Pulse draft protection, request correlation and fallback handoff staging; improved Chronicle scrolling, traversal completion and safe cancellation.
- Corrected stale and overlapping Abyss search results, including safe Clear behavior and a dismissible results panel.
- Improved Portal focus confirmation, draft preservation and recovery of images that have not been pasted.
- Added native Return to ChatGPT recovery on external sign-in pages, without injecting VAL controls or scripts into the provider page.
- Applied the approved layered gunmetal rim, recessed seam, blue reflection and dark glass treatment to VAL-owned controls and framed panels.
- Anchored Control Centre beside the current ChatGPT header actions, with direct dragging, resizing, automatic placement reset, and compact-panel safeguards.
- Added F6/Shift+F6 access to native controls, Enter/Space activation, focus-return keys, and larger, brighter Control Centre text.
- Expanded automated regression/integration coverage and isolated publish, installer, repair, upgrade/rollback and data-retention validation.

## Installation

Download `VAL_Setup_v5.1.0.exe` and its adjacent SHA-256 checksum from this release. The installer is per-user and does not require administrator elevation. Microsoft Edge WebView2 Runtime is required; .NET does not need to be installed separately for this self-contained build.

Before upgrading, close VAL and back up your existing `%LOCALAPPDATA%\VAL` folder while the app is closed. Keep the v5.0.0 installer if you may need to roll back. Local tests cover explicit uninstall with data retention followed by baseline reinstall; installing an older version directly over newer files is not a validated rollback path.

## Validation And Limits

The reviewed source passes 389 .NET tests, 82 client checks, and 20 grouped local published/isolated installer and upgrade/rollback gates. Manual isolated checks also covered authenticated synthetic workflows, sign-out/data wipe, native provider return, adaptive placement, and keyboard access. Historical browser checks remain identified by the exact candidate they tested; they are not blanket certification of every behavior in a rebuilt release.

Native WPF test classes run in a serialized group with a bounded cold-initialization allowance, correcting a hosted-runner test timeout without removing assertions or skipping tests.

This is an **unsigned build released for user testing**, not a claim of commercial-release certification. Windows may display an unknown-publisher or reputation warning. Code signing, the original-production-installer supported-machine matrix, broader screen-reader/DPI/multi-monitor testing, provider-pill Alt+F4, model-enriched Pulse timing, long-session performance, and remaining live failure-path checks are still outstanding. Appropriate distribution licensing, privacy/legal review and a supported update/rollback channel also remain product requirements.

Archive content deduplication retains distinct content, not necessarily the exact multiplicity of identical repeated messages. Chronicle is not a lossless per-turn transcript guarantee. VAL's tools depend on ChatGPT's evolving interface, so report any navigation, focus, capture or placement regressions.

When reporting an issue, include the VAL version, steps to reproduce, and a screenshot if useful. Do not include credentials, browser profiles, or personal conversation content in public issues.
